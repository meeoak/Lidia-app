## 🎯 Level 3의 핵심 가치

- 매니저: 매일 시트 열어서 승인 처리, D-Day 확인

## 🛠️ Apps Script란?

### 정의
Google Workspace 자동화를 위한 JavaScript 기반 스크립트 언어.

### 특징
- 무료 (Workspace 사용자)
- Google Sheets/Forms/Drive와 깊은 통합
- 트리거 (시간/이벤트 기반 자동 실행)
- 외부 API 호출 가능 (왓츠앱, Slack 등)

### 한계
- 일일 트리거 실행 시간: 90분 (무료), 6시간 (Workspace)
- 이메일 발송: 100건/일 (무료), 1500건/일 (Workspace)
- URL Fetch 호출: 20,000건/일

## 💡 자주 묻는 질문

### Q1. 코딩 모르는데 적용 가능한가요?
A. 각 스크립트는 **복붙 가능한 형태**로 제공됩니다. 다음만 수정하면 됩니다:
- 시트 ID
- 이메일 주소
- 일부 변수

### Q2. 무료 Gmail 계정으로도 가능?
A. 가능합니다. 단:
- 이메일 발송 한도: 100건/일 → 큰 팀은 제한적
- 트리거 실행: 90분/일 → 충분함
- **권장**: Google Workspace 사용 (한도 ↑)

### Q3. 왓츠앱 알림은 어떻게?
A. 두 가지 옵션:
1. **이메일 → 왓츠앱 자동 전달** (무료): Gmail 필터 + 왓츠앱 이메일 통합
2. **Twilio API 직접 호출** (유료): $0.005/메시지

권장: 처음에는 이메일만, 1개월 후 왓츠앱 추가 검토.

### Q4. Apps Script 권한이 무서워요
A. 필요 권한:
- 시트 읽기/쓰기 (운영 시트만)
- 이메일 발송 (본인 Gmail)
- 트리거 실행

악의적인 사용 없음. 본인 계정에서만 실행.

### Q5. 코드 수정 어렵나요?
A. 기본 사용은 변수만 수정. 단:
- 로직 변경 시: JavaScript 기초 필요
- **권장**: 본부장 또는 IT 담당자가 관리

## ⚠️ 시작 전 주의사항

### 1. 백업 필수
Apps Script가 시트 데이터를 자동 수정합니다.
**반드시 시작 전 시트 백업**.

### 2. 테스트 환경
실제 운영 시트가 아닌 **테스트 사본**으로 먼저 시도.

### 3. 권한 신중
Apps Script는 시트의 모든 데이터에 접근 가능.
프로덕션 적용 전 코드 검토.

### 4. 트리거 한도
하루 90분 (무료) 초과 시 트리거 일시 중단.
Google Workspace 권장.

### 5. 에러 처리
초기에는 에러 발생 가능. 매일 트리거 실행 결과 모니터링.
