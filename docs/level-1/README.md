## ✅ Level 1 완료 체크리스트

각 항목 완료 시 체크하세요:

### 드롭다운 + 입력 검증
- [ ] 매니저 승인 컬럼: 승인/반려/대기 드롭다운
- [ ] 클로징 신호 컬럼: 강/중/약 드롭다운
- [ ] 실패 사유 컬럼: 9가지 카테고리 드롭다운
- [ ] 에이전트 이름 컬럼: 전체 에이전트 리스트 드롭다운
- [ ] 교사 이름 컬럼: 전체 교사 리스트 드롭다운

### 조건부 서식
- [ ] D-Day 임박 (D-3 이내): 자동 빨강
- [ ] 클로징 신호 강: 초록 / 중: 노랑 / 약: 빨강
- [ ] 매니저 승인: 승인 초록 / 반려 빨강 / 대기 노랑
- [ ] 빈 셀: 회색 (입력 필요 알림)

### D-Day 자동 계산
- [ ] 재클로징 데드라인 D-Day 컬럼 자동 계산
- [ ] 수업 D-Day 컬럼 자동 계산
- [ ] 마감 지난 케이스 "마감" 표시
- [ ] 토/일 제외 영업일 계산 (선택)

### 필터 뷰
- [ ] 에이전트별 필터 뷰 (10명+ 각각)
- [ ] 교사별 필터 뷰 (10명+ 각각)
- [ ] 매니저 필터 뷰 (승인 대기만)
- [ ] 본부장 필터 뷰 (전체)

### 시트 보호
- [ ] 운영 가이드 시트: 매니저 외 읽기 전용
- [ ] 헤더 행: 매니저 외 편집 불가
- [ ] 수식 컬럼 (D-Day 등): 편집 불가
- [ ] 완료된 케이스: 잠금 (사후 변경 방지)

## ⚠️ 시작 전 필수 작업

### 1. 백업
```
Google Sheets → 파일 → 사본 만들기
이름: "Lidia 운영시트 백업 YYYY-MM-DD"
```

### 2. 작업용 사본
```
Google Sheets → 파일 → 사본 만들기
이름: "Lidia 운영시트 v2 (Level 1 작업중)"
```

작업용 사본에서 모든 변경 작업을 진행하고, 검증 후 원본을 교체하세요.

## 🆘 트러블슈팅

### 드롭다운이 안 보여요
- 데이터 → 데이터 확인 → 적용 범위 확인
- "데이터 확인 도움말 텍스트 표시" 체크

### 조건부 서식이 다른 행에 적용돼요
- 범위 다시 확인 (예: A2:A1000)
- 절대/상대 참조 확인 ($A$2 vs A2)

### 수식이 #REF! 오류
- 참조 범위 확인 (다른 시트 참조 시 시트명 따옴표 필요)
- 데이터 → 범위 정의로 명명된 범위 사용 권장
