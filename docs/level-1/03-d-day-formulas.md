# Level 1 - Step 3: D-Day 자동 계산

> **목표**: 데드라인 카운트다운 자동화
> **소요 시간**: 30분
> **선행 작업**: 신청일/수업일 등 날짜 컬럼 존재

---

## 🎯 왜 필요한가?

### Before
- 매니저: "이거 신청일이 5/10이니까... 오늘이 5/19니까... 9일 지났네... 재클로징 3일 룰이면 끝났네!"
- 매번 머리로 계산 → 실수, 누락

### After
- D-Day 컬럼에 `D-3`, `D-1`, `마감` 자동 표시
- 조건부 서식과 결합 → 빨강으로 즉시 인지

---

## 📐 적용할 D-Day 수식

| # | 용도 | 수식 |
|---|---|---|
| 1 | 재클로징 데드라인 (3일) | `=IF(ISBLANK(B2), "", IF(B2+3-TODAY()<0, "마감", "D-"&(B2+3-TODAY())))` |
| 2 | 수업 예정일 카운트다운 | `=IF(ISBLANK(J2), "", IF(J2-TODAY()<0, "지남", "D-"&(J2-TODAY())))` |
| 3 | 영업일 기준 D-Day (토일 제외) | `=NETWORKDAYS(TODAY(), B2+3)` |
| 4 | 시간 단위 (당일 마감) | `=IF(TODAY()=B2, "오늘", "D-"&(B2-TODAY()))` |

---

## 🛠️ 실행 단계

### Step 1: 재클로징 데드라인 D-Day

**전제**: B 컬럼에 "신청일" 또는 "수업일" 등 기준 날짜 존재

#### 1-1. 수식 입력

1. D-Day 컬럼 선택 (예: `Q2`)
2. 다음 수식 입력:

```excel
=IF(
  ISBLANK(B2),
  "",
  IF(
    B2 + 3 - TODAY() < 0,
    "마감",
    "D-" & (B2 + 3 - TODAY())
  )
)
```

#### 1-2. 수식 설명

- `ISBLANK(B2)`: 날짜 비어있으면 빈칸 반환
- `B2 + 3`: 기준일 + 3일 (재클로징 데드라인)
- `B2 + 3 - TODAY()`: 남은 일수 계산
- `< 0`: 지났으면 "마감"
- 그 외: "D-" + 남은 일수

#### 1-3. 아래로 복사

1. `Q2` 셀 선택
2. 오른쪽 하단 모서리 드래그 → `Q1000`까지
3. 또는 `Q2` 복사 → `Q3:Q1000` 붙여넣기

---

### Step 2: 수업 예정일 카운트다운

수업 예정일까지 며칠 남았는지 표시.

```excel
=IF(
  ISBLANK(J2),
  "",
  IF(
    J2 - TODAY() < 0,
    "지남",
    IF(
      J2 - TODAY() = 0,
      "오늘",
      "D-" & (J2 - TODAY())
    )
  )
)
```

- 수업일 입력 안 됨: 빈칸
- 수업일 지남: "지남"
- 오늘 수업: "오늘"
- 미래: "D-N"

---

### Step 3: 영업일 기준 D-Day (토일 제외)

주말 제외하고 계산하려면:

```excel
=IF(
  ISBLANK(B2),
  "",
  IF(
    NETWORKDAYS(TODAY(), B2 + 3) <= 0,
    "마감",
    "D-" & (NETWORKDAYS(TODAY(), B2 + 3) - 1)
  )
)
```

`NETWORKDAYS(시작일, 종료일)`: 영업일 수 계산 (토/일 자동 제외)

#### 인도네시아 공휴일 제외하기

`옵션마스터` 시트에 공휴일 리스트 추가:

```
F1: 공휴일
F2: 2026-01-01    (신정)
F3: 2026-01-29    (구정)
F4: 2026-03-19    (Nyepi)
F5: 2026-04-10    (Idul Fitri 1일차)
F6: 2026-04-11    (Idul Fitri 2일차)
F7: 2026-05-01    (노동절)
... (전체 추가)
```

수식 수정:

```excel
=IF(
  ISBLANK(B2),
  "",
  IF(
    NETWORKDAYS(TODAY(), B2 + 3, 옵션마스터!$F$2:$F$50) <= 0,
    "마감",
    "D-" & (NETWORKDAYS(TODAY(), B2 + 3, 옵션마스터!$F$2:$F$50) - 1)
  )
)
```

---

### Step 4: 자동 정렬 컬럼 (긴급 순)

긴급도 순으로 자동 정렬하려면 별도 정렬용 컬럼 추가:

```excel
=IF(
  ISBLANK(B2),
  9999,
  IF(
    B2 + 3 - TODAY() < 0,
    -1,
    B2 + 3 - TODAY()
  )
)
```

- 입력 안 됨: 9999 (제일 뒤)
- 마감 지남: -1 (제일 앞)
- 그 외: 남은 일수

이 컬럼으로 정렬하면 긴급 순.

---

### Step 5: 클로징 기회 잔여 일수 표시

여러 데드라인이 있을 때 가장 임박한 것 자동 표시:

```excel
=IFERROR(
  MIN(
    IF(B2+3-TODAY()>=0, B2+3-TODAY(), 9999),
    IF(J2-TODAY()>=0, J2-TODAY(), 9999)
  ),
  ""
)
```

배열 수식이므로 `Ctrl+Shift+Enter`로 입력 (또는 Google Sheets는 자동).

## 🎨 D-Day 표시 형식 옵션

### 옵션 A: "D-N" 형식 (기본)
```
D-3, D-2, D-1, 마감
```

### 옵션 B: 이모지 포함
```excel
=IF(
  ISBLANK(B2),
  "",
  IF(
    B2 + 3 - TODAY() < 0,
    "🔴 마감",
    IF(
      B2 + 3 - TODAY() <= 1,
      "🔴 D-" & (B2 + 3 - TODAY()),
      IF(
        B2 + 3 - TODAY() <= 3,
        "🟡 D-" & (B2 + 3 - TODAY()),
        "🟢 D-" & (B2 + 3 - TODAY())
      )
    )
  )
)
```

### 옵션 C: 날짜 + 카운트다운
```excel
=IF(
  ISBLANK(B2),
  "",
  TEXT(B2+3, "M/D") & " (D-" & (B2+3-TODAY()) & ")"
)
```

결과: `5/15 (D-3)`

## 🔧 더 정교한 D-Day 시스템

### 케이스별 데드라인 차등 적용

실패 사유에 따라 데드라인이 다르다면:

```excel
=IF(
  ISBLANK(B2),
  "",
  IF(
    LEFT(F2, 1) = "①",   F2가 실패 사유 컬럼
    IF(B2+5-TODAY()<0, "마감", "D-"&(B2+5-TODAY())),   ① 남편 반대: 5일
    IF(B2+3-TODAY()<0, "마감", "D-"&(B2+3-TODAY()))    그 외: 3일
  )
)
```

### 매니저 승인 후부터 카운트

신청일이 아닌 매니저 승인일부터 D-Day 계산:

```excel
=IF(
  OR(ISBLANK(G2), H2<>"승인"),   G2: 승인일, H2: 승인 상태
  "",
  IF(
    G2 + 3 - TODAY() < 0,
    "마감",
    "D-" & (G2 + 3 - TODAY())
  )
)
```

## ⚠️ 자주 발생하는 실수

### 1. 날짜 형식 오류
**증상**: 수식 결과가 `#VALUE!` 또는 이상한 숫자
**원인**: 날짜 컬럼이 "텍스트"로 저장됨
**해결**:
1. 날짜 컬럼 선택
2. 서식 → 숫자 → 날짜
3. 또는 `=DATEVALUE(B2)` 사용

### 2. TODAY() 갱신 안 됨
**증상**: 어제 D-3이었는데 오늘도 D-3
**원인**: 시트가 닫혀있었음
**해결**: 시트 새로고침 또는 셀 재계산

### 3. 빈 셀에 "마감" 표시
**증상**: 날짜 비어있는데 "마감"이라고 나옴
**원인**: `ISBLANK` 체크 누락
**해결**: 수식 시작에 `IF(ISBLANK(B2), "", ...)` 추가

### 4. 음수 표시
**증상**: 마감 지난 케이스 `D--3`처럼 표시
**원인**: 음수 처리 안 됨
**해결**: `IF(B2+3-TODAY()<0, "마감", ...)` 추가

## ✅ 완료 확인

다음을 테스트하세요:

1. **오늘 날짜 입력**: B2에 `=TODAY()` → D-Day에 `D-3`?
2. **3일 전 날짜 입력**: B2에 `=TODAY()-3` → D-Day에 `D-0` 또는 `오늘`?
3. **5일 전 날짜 입력**: B2에 `=TODAY()-5` → D-Day에 `마감`?
4. **빈 셀**: B2 비우기 → D-Day도 빈칸?
5. **조건부 서식 연동**: D-Day가 빨강/주황으로 자동 변경?
