# Level 1 - Step 4: 역할별 필터 뷰

> **목표**: 본인 관련 케이스만 빠르게 확인
> **소요 시간**: 30분
> **선행 작업**: 에이전트/교사 마스터 시트 존재

---

## 🎯 왜 필요한가?

### Before
에이전트 GiAR가 본인 케이스 확인하려면:
1. 전체 시트 열기
2. Ctrl+F로 "GiAR" 검색
3. 일치하는 행 하나씩 확인
→ 5분 소요

### After
1. 시트 우측 상단 "GiAR 뷰" 클릭
2. 본인 케이스만 표시됨
→ 5초

## 🛠️ 실행 단계

### Step 1: 필터 뷰 생성 (개념 이해)

**중요**: 일반 "필터"가 아닌 **"필터 뷰"** 사용!

| 구분 | 일반 필터 | 필터 뷰 |
|---|---|---|
| 다른 사용자에게 영향 | 모두에게 보임 | 본인만 보임 |
| 동시 작업 | 충돌 발생 | 가능 |
| 저장 | 안 됨 | 저장됨 |
| 추천 | ❌ | ✅ |

**접근 방법**:
- 메뉴: 데이터 → 필터 뷰 → 새 필터 뷰 만들기
- 또는: 깔때기 아이콘 옆 화살표 클릭

---

### Step 2: 에이전트별 필터 뷰 생성

#### 2-1. GiAR 필터 뷰

1. **데이터 → 필터 뷰 → 새 필터 뷰 만들기**
2. 검은색 테두리가 생기면서 필터 뷰 모드 진입
3. 좌측 상단 이름 입력: `[에이전트] GiAR`
4. 에이전트 컬럼(C열) 깔때기 클릭
5. **값별 필터링** → "선택 해제" → "GiAR"만 체크
6. **확인**
7. 우측 상단 `×` 클릭 → 필터 뷰 저장됨

#### 2-2. 추가 정렬

```
필터 뷰 안에서:
1. D-Day 컬럼 깔때기 클릭
2. "A → Z 정렬" 선택
   → 긴급한 순서로 자동 정렬
```

#### 2-3. 나머지 에이전트 반복

10명+ 전체에 대해 반복. 빠르게 하는 방법:

**복제 후 수정**:
1. GiAR 필터 뷰 열기
2. 데이터 → 필터 뷰 → 필터 뷰 옵션 → **복사**
3. 새 이름으로 변경: `[에이전트] TINA`
4. 에이전트 필터만 변경 (GiAR → TINA)

---

### Step 3: 교사별 필터 뷰 생성

에이전트와 동일한 방식으로 교사별 뷰 생성.

```
[교사] Bu Rina:
  - 교사 컬럼 = "Bu Rina"
  - 수업일 컬럼 오름차순 정렬

[교사] Bu Sari:
  - 교사 컬럼 = "Bu Sari"
  - 수업일 컬럼 오름차순 정렬
```

---

### Step 4: 매니저용 필터 뷰

#### 4-1. 승인 대기 (가장 자주 사용)

```
이름:           [매니저] 승인 대기
필터:           매니저 승인 = "대기"
정렬:           신청일 오름차순 (오래된 순)
```

#### 4-2. 진행 중

```
이름:           [매니저] 진행 중
필터:
  매니저 승인 = "승인"
  AND 수업 결과 = (빈칸)
정렬:           D-Day 오름차순
```

**복합 조건 입력 방법**:
1. 매니저 승인 컬럼 필터 → "승인"만 체크
2. 수업 결과 컬럼 필터 → "(빈칸)"만 체크

#### 4-3. D-Day 임박

```
이름:           [매니저] D-Day 임박
필터:
  D-Day 컬럼 → 조건별 필터링
  → 텍스트가 다음으로 시작:
    값1: "D-1"
    값2: "D-2"
    값3: "D-3"
    값4: "마감"
```

---

### Step 5: 본부장용 필터 뷰

#### 5-1. 이번 주 신규 신청

```
이름:           [본부장] 이번 주 신규
필터:
  신청일 → 조건별 필터링
  → 다음 이후 날짜:
    =TODAY()-WEEKDAY(TODAY(),2)+1
    (오늘이 속한 주의 월요일)
정렬:           신청일 내림차순
```

#### 5-2. 이번 달 성공

```
이름:           [본부장] 이번 달 성공
필터:
  수업 결과 = "성공"
  AND 수업일 → 조건별 필터링
    → 다음 이후:
      =EOMONTH(TODAY(),-1)+1
      (이번 달 1일)
```

#### 5-3. 에이전트별 성과

```
이름:           [본부장] 에이전트별 성과
필터:           (없음 - 전체 보기)
정렬:
  1순위: 에이전트 (A→Z)
  2순위: 신청일 (내림차순)
```

---

### Step 6: 공유 vs 개인 필터 뷰

#### 공유 필터 뷰 (모든 팀원이 접근)
- 위에서 만든 모든 뷰가 기본적으로 공유 필터 뷰
- 누구나 데이터 → 필터 뷰 메뉴에서 선택 가능
- 누군가 수정하면 모두에게 영향

#### 임시 필터 뷰 (본인만)
1. 데이터 → 필터 뷰 → 새 임시 필터 뷰 만들기
2. 저장 안 됨, 시트 닫으면 사라짐
3. 빠른 검색 시 유용

---

## 🔗 필터 뷰 URL 공유

각 필터 뷰마다 고유 URL이 있어 직접 링크 공유 가능:

1. 필터 뷰 열기
2. 브라우저 주소창 확인: `...&fvid=12345`
3. URL 복사 → 해당 사람에게 공유

**활용**:
- GiAR 이메일 시: "본인 케이스 확인: [필터 뷰 URL]"
- 매니저 북마크: 승인 대기 필터 뷰 URL을 즐겨찾기
- 본부장: 이번 주 성과 뷰 URL을 매주 월요일 자동 발송 (Level 3 자동화)

---

## 🎯 필터 뷰 명명 규칙

찾기 쉽도록 일관된 규칙 적용:

```
[역할] 이름 - 용도

예시:
[에이전트] GiAR
[교사] Bu Rina
[매니저] 승인 대기
[매니저] D-Day 임박
[본부장] 이번 주 성과
[매니저] X 보류 케이스 분석
```

- 대괄호 안 역할명으로 그룹화
- 알파벳 정렬 시 같은 역할끼리 모임

## 🔧 고급: 동적 필터 뷰 (조건 자동 변경)

### "이번 주" 자동 갱신

```
필터 조건:
신청일 >= =TODAY()-WEEKDAY(TODAY(),2)+1

매주 월요일에 자동으로 "이번 주" 범위 갱신됨.
```

### "이번 달" 자동 갱신

```
필터 조건:
신청일 >= =EOMONTH(TODAY(),-1)+1
신청일 <= =EOMONTH(TODAY(),0)
```

### "최근 7일" 자동 갱신

```
필터 조건:
신청일 >= =TODAY()-7
```

## ⚠️ 자주 발생하는 실수

### 1. "필터" vs "필터 뷰" 혼동
- **일반 필터**: 모두에게 영향, 동시 작업 불가
- **필터 뷰**: 본인만 영향, 동시 작업 가능
- 항상 **필터 뷰** 사용!

### 2. 필터 뷰 이름 미입력
- 기본 이름: "필터 1", "필터 2" → 찾기 어려움
- 항상 의미 있는 이름 입력

### 3. 필터 뷰 너무 많이 생성
- 100개 넘으면 관리 어려움
- 정기적으로 안 쓰는 필터 뷰 삭제

### 4. 데이터 범위 변경 시 필터 뷰 깨짐
- 행 추가/삭제 시 필터 뷰 범위가 따라가지 않을 수 있음
- 정기적으로 필터 뷰 확인 필요
