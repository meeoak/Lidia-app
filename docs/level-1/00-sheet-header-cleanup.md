# Level 1 - Step 0: 시트 헤더·구조 정리 (가장 먼저!)

> **목표**: "OFF라인 Bimbel 1차 수업 요청 트래커" 시트의 컬럼명·구조를 명확하게 다듬어, 누구나 (특히 교사가) 한 번에 이해할 수 있게 하기
> **소요 시간**: 1~2시간
> **선행 작업**: 시트 백업 (Sheets → 파일 → 사본 만들기) **필수**

---

## 🎯 왜 가장 먼저인가?

지금 시트엔 다음 문제들이 있습니다:

1. **`매니저 승인` 컬럼이 2개** — 영업 매니저용과 빔블 매니저용 둘 다 같은 이름. 누가 뭘 승인했는지 시트만 봐선 모름.
2. **데이터가 컬럼 의미와 맞지 않음** — 예: `Waktu Kunjungan 1` (수업 *시간*) 칸에 `Visit Selesai (방문완료)` 같은 *상태값*이 들어 있음. 입력자가 컬럼 뜻을 헷갈리고 있다는 증거.
3. **`Memo Pelanggan` 한 칸에 4가지 정보** (활동·우려·평가·사진) 우겨넣게 만들어둠 → 검색·필터 불가, 모바일에서 잘림.
4. **`실패 상세 사유`인데 영업은 계속 진행** → 단어 자체가 잘못. "보류 사유"가 맞음.
5. **한국어와 인도네시아어가 무작위로 섞여 있음** → 양쪽 사용자 모두 헷갈림.

이걸 그대로 두면 드롭다운·조건부서식·집계 모두 깨지므로 **다른 Level 1 작업을 시작하기 전에 먼저** 정리합니다.

## 🛠️ 적용 단계

### Step 1: 백업 (필수)

```
파일 → 사본 만들기 → 이름: "Bimbel 트래커 백업 YYYY-MM-DD"
```

### Step 2: 헤더 셀 일괄 수정

각 셀을 더블클릭해서 새 문구로 교체. 위 변경표 그대로.

**팁**: 헤더 행이 2줄로 되어 있다면 (Phase 헤더 + 컬럼 헤더), 두 줄을 모두 확인하세요.

### Step 3: Memo Pelanggan 컬럼 분할

이 단계는 데이터 이동이 필요해서 가장 손이 많이 갑니다.

#### 3-1. 기존 메모 컬럼 옆에 빈 컬럼 3개 추가

```
원래 컬럼: T (Memo Pelanggan)
추가: U, V, W (빈 컬럼 3개를 우측에 삽입)
```

방법: T 컬럼 우클릭 → "오른쪽에 열 1개 삽입" × 3회.

#### 3-2. 헤더 입력

```
T: 수업 활동 / Kegiatan
U: 학부모 우려사항 / Concern Parents
V: 학습 평가 / Hasil Evaluasi
W: 방문 사진 링크 / Foto Form (URL)
```

#### 3-3. 기존 메모 데이터 분리

기존 메모 셀에 4가지 정보가 함께 들어 있다면:
- "1. ~~~" 부분 → T 컬럼
- "2. ~~~" 부분 → U 컬럼
- "3. ~~~" 부분 → V 컬럼
- "4. ~~~" 부분 → W 컬럼

데이터가 많으면 매니저 1명이 1~2시간 작업.

> 💡 데이터가 너무 많으면 Apps Script로 자동 분리 가능. 필요 시 Level 3 가이드 참고.

### Step 4: "자녀몰입도" 값 변환

기존 값(강/중/약) → 새 값(적극/보통/소극)

#### 빠른 일괄 변환

```
Ctrl+F → "찾기 및 바꾸기"
- 찾기: 강    → 바꾸기: 적극
- 찾기: 중    → 바꾸기: 보통
- 찾기: 약    → 바꾸기: 소극
```

> ⚠️ **주의**: "찾기"에 "강"만 치면 "강아지" 같은 다른 셀의 글자도 바꿔버립니다.
> 반드시 **"전체 일치"** 옵션 켜고, 해당 컬럼(자녀몰입도 컬럼) 범위만 선택해서 진행하세요.

### Step 5: 데이터 검증

샘플 행 5개로 다음을 확인:

```
□ 수업 시간 컬럼에 시간 형식(HH:MM)이 들어 있는가? (상태값 X)
□ 방문 결과 컬럼에 완료/예정/취소 중 하나가 들어 있는가?
□ Memo 4분할 컬럼이 각자 올바른 내용을 담고 있는가?
□ 자녀 반응이 적극/보통/소극으로 변환됐는가?
□ 두 매니저 승인 컬럼이 구분되어 있는가?
```

### Step 6: 드롭다운 재적용

헤더 변경 후 기존 드롭다운 범위가 안 맞을 수 있으니, **[Level 1 - Step 1: 드롭다운 + 입력 검증](./01-dropdowns-validation.md)** 가이드 따라 재설정하세요.

**주요 드롭다운**:

| 컬럼 | 옵션 |
|---|---|
| 보류 사유 | ① 남편 반대 / ② 큰 지출 부담 / ③ 우선순위 미흡 / ④ 결정 지연 / ⑤ 효과 의구심 / ⑥ 학원 대안 고려 / ⑦ 자녀 거부 / ⑧ 가격 부담 / ⑨ 기타 |
| 영업매니저 승인 | 승인 / 반려 / 대기 / 보류 |
| 빔블매니저 승인 | 승인 / 반려 / 대기 |
| 방문 결과 / Status Visit | 완료 (Selesai) / 예정 (Belum) / 취소 (Batal) |
| 자녀 반응 / Reaksi Anak | 적극 (Aktif) / 보통 (Sedang) / 소극 (Pasif) |
| 최종 결과 | 성공 / 보류 / 실패 |

## 🎁 (선택) 보너스: 학부모 계약 의향 컬럼 신설

현재 시트엔 **자녀 반응**만 있고, **학부모의 계약 의향(곧 결정 가능한지)** 컬럼이 따로 없습니다.

영업 재상담 시점을 정확히 잡으려면 이 컬럼이 큰 도움이 됩니다:

```
신설 컬럼 위치: 자녀 반응 우측 (X 컬럼쯤)
이름: 학부모 계약 의향 / Closing Signal (강/중/약)
교사가 수업 후 입력:
  - 강: 학부모가 "곧 결정하겠다" 분위기
  - 중: 관심 있지만 시간 필요
  - 약: 관심 낮음·추가 자료 필요
```

> 💡 이 컬럼은 *선택*입니다. 운영 1-2주 해보고 영업팀이 "재상담 타이밍 잡기가 어렵다"고 하면 추가하세요.

## ⚠️ 자주 하는 실수

### 1. 백업 없이 시작
→ Memo 컬럼 분할하다가 데이터 날아가면 복구 불가. **반드시 백업 먼저.**

### 2. 헤더만 바꾸고 데이터는 그대로
- "Waktu Kunjungan 1" 헤더만 "수업 시간"으로 바꾸고 데이터 칸엔 여전히 "Visit Selesai" 같은 상태값이 있는 경우가 흔합니다.
- 헤더 변경 후 **데이터 검증 5번** 꼭 수행.

### 3. Phase 헤더(상단 그룹 헤더)와 컬럼 헤더 혼동
- 1행: Phase 그룹 (① ② ③ ④ ⑤)
- 2행: 실제 컬럼 헤더
- 둘 다 다듬되, **수식·드롭다운은 2행 헤더만 신경** 쓰면 됨.

### 4. 드롭다운에 "전체 일치" 안 함
→ "강"으로 검색해서 "강아지" 들어간 셀까지 바뀔 수 있음.

## ✅ 완료 확인

```
□ 시트 백업 완료
□ 모든 컬럼 헤더가 변경표대로 다듬어짐
□ 두 "매니저 승인" 컬럼이 "영업매니저 승인" / "빔블매니저 승인"으로 구분됨
□ Memo Pelanggan 4분할 완료 + 기존 데이터 분리 완료
□ 자녀 반응 컬럼 값이 적극/보통/소극으로 변환됨
□ 드롭다운 재설정 완료
□ 샘플 행 5개 데이터 검증 OK
```

모두 완료되면 **[Level 1 - Step 1: 드롭다운 + 입력 검증](./01-dropdowns-validation.md)**으로 이동!
