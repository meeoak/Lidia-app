> **소요 시간**: 45분
> **선행 작업**: Step 1 완료 (드롭다운)

## 🛠️ 실행 단계

### Step 1: D-Day 조건부 서식

**전제**: D-Day 컬럼이 존재해야 함 (없으면 Step 3 먼저 적용 후 돌아오기)

#### 1-1. D-1 이하 (긴급) - 빨강

1. D-Day 컬럼 선택 (예: `Q2:Q1000`)
2. **서식 → 조건부 서식**
3. 설정:

```
조건:          맞춤 수식이 다음과 같음
수식:          =AND(ISNUMBER(VALUE(REGEXEXTRACT(Q2,"\d+"))), VALUE(REGEXEXTRACT(Q2,"\d+"))<=1, LEFT(Q2,2)="D-")
서식 스타일:
  배경:        #FFFFFF (흰색)
  글자:        #CC0000 (빨강)
  굵게:        ✅
```

**대안 (D-Day가 숫자만 저장된 경우)**:
```
수식:    =AND(ISNUMBER(Q2), Q2<=1, Q2>=0)
```

#### 1-2. D-3 이하 (주의) - 주황

```
범위:    Q2:Q1000
수식:    =AND(ISNUMBER(VALUE(REGEXEXTRACT(Q2,"\d+"))), VALUE(REGEXEXTRACT(Q2,"\d+"))<=3, VALUE(REGEXEXTRACT(Q2,"\d+"))>1, LEFT(Q2,2)="D-")
배경:    #FFFFFF
글자:    #FF6600 (주황)
굵게:    ✅
```

#### 1-3. 마감 - 진빨강 배경

```
범위:    Q2:Q1000
수식:    =Q2="마감"
배경:    #CC0000 (진빨강)
글자:    #FFFFFF (흰색)
굵게:    ✅
```

**중요**: 규칙 순서가 위에서 아래로 적용됨. **"마감"을 가장 위로**, 그 다음 D-1, D-3 순서.

---

### Step 2: 클로징 신호 색상

#### 2-1. 강 - 초록

1. 클로징 신호 컬럼 선택 (예: `L2:L1000`)
2. **서식 → 조건부 서식**

```
조건:          텍스트가 정확히 일치
값:           강
배경:          #B7E1CD (연한 초록)
글자:          #0D652D (진초록)
```

#### 2-2. 중 - 노랑

```
조건:          텍스트가 정확히 일치
값:           중
배경:          #FFE599 (연한 노랑)
글자:          #7F6000 (진노랑/갈색)
```

#### 2-3. 약 - 빨강

```
조건:          텍스트가 정확히 일치
값:           약
배경:          #F4C7C3 (연한 빨강)
글자:          #B6362A (진빨강)
```

---

### Step 3: 매니저 승인 색상

```
범위: H2:H1000 (매니저 승인 컬럼)

승인: 배경 #B7E1CD, 글자 #0D652D
반려: 배경 #F4C7C3, 글자 #B6362A
대기: 배경 #FFF2CC, 글자 #BF9000
보류: 배경 #D9D9D9, 글자 #666666
```

---

### Step 4: 입력 미완료 알림 (회색)

필수 입력 컬럼이 비어있을 때 회색 배경으로 알림.

```
범위:    A2:Z1000 (전체)
조건:    맞춤 수식
수식:    =AND($A2<>"", OR($B2="", $C2="", $D2=""))
         ($A2: NO 컬럼 채워짐, $B2/$C2/$D2: 필수 컬럼 중 하나라도 비어있음)
배경:    #EFEFEF (연한 회색)
```

**적용 후**: 필수 정보 빠진 행은 자동으로 회색 처리 → 한눈에 확인 가능

---

### Step 5: 성공 케이스 강조 (연한 초록 배경)

수업 결과가 "성공"인 행 전체를 연한 초록으로.

```
범위:    A2:Z1000
조건:    맞춤 수식
수식:    =$M2="성공"
         ($M2: 수업 결과 컬럼)
배경:    #E6F4EA (매우 연한 초록)
```

---

### Step 6: 마감 지난 케이스 (전체 행 회색)

```
범위:    A2:Z1000
조건:    맞춤 수식
수식:    =$Q2="마감"
배경:    #E0E0E0 (회색)
글자:    #999999 (연한 글자)
```

## 📋 조건부 서식 우선순위 정리

규칙이 충돌할 때 **위 규칙이 우선** 적용됩니다. 다음 순서로 정렬하세요:

```
1. 마감 (진빨강 배경)         ← 가장 위
2. D-1 이하 (빨강 글자)
3. D-3 이하 (주황 글자)
4. 매니저 승인: 반려
5. 매니저 승인: 승인
6. 매니저 승인: 대기
7. 매니저 승인: 보류
8. 클로징 신호: 강
9. 클로징 신호: 중
10. 클로징 신호: 약
11. 수업 결과: 성공 (전체 행)
12. 입력 미완료 (회색 배경)   ← 가장 아래
```

순서 변경: 조건부 서식 패널에서 규칙을 드래그.

## ⚠️ 자주 발생하는 실수

### 1. 범위에 절대참조 누락
❌ `=Q2="마감"` (행 번호 자동 변경됨)
✅ `=$Q2="마감"` (열 고정, 행 자동)

전체 행을 색칠하려면 **열에 `$`** 필요.

### 2. 텍스트 일치 vs 포함
- "텍스트가 정확히 일치": "강"만 매치 (✅ 추천)
- "텍스트에 다음 포함": "강함", "강", "강력" 모두 매치 (위험)

### 3. 중복 범위
같은 범위에 여러 규칙 적용 시 → 첫 매치 규칙만 적용됨.
"마감"은 최상위로, "입력 미완료"는 최하위로 배치.

### 4. 수식의 따옴표
❌ `=Q2=마감` (마감을 셀 참조로 해석)
✅ `=Q2="마감"` (텍스트로 해석)
