# Level 1 - Step 1: 드롭다운 + 입력 검증

> **목표**: 입력값 통일로 오타/오류 방지
> **소요 시간**: 30분
> **선행 작업**: 시트 백업 완료

---

## 🎯 왜 필요한가?

### Before
- 에이전트 A: "강"
- 에이전트 B: "Strong"
- 에이전트 C: "강함"
→ 필터/집계 불가능

### After
- 모두: "강" (드롭다운에서만 선택 가능)
→ 자동 집계 가능, 조건부 서식 정확히 적용

---

## 📝 적용할 드롭다운 목록

| 컬럼명 | 옵션 | 비고 |
|---|---|---|
| 매니저 승인 | 승인 / 반려 / 대기 / 보류 | 매니저만 편집 |
| 클로징 신호 | 강 / 중 / 약 | 교사가 수업 후 입력 |
| 실패 사유 | 9가지 카테고리 | 에이전트 입력 |
| 에이전트 | 전체 에이전트 리스트 | 새 케이스 입력 시 |
| 교사 | 전체 교사 리스트 | 매니저 배정 시 |
| 수업 결과 | 성공 / 보류 / 실패 / 미진행 | 교사 입력 |
| 재클로징 결과 | 성공 / 진행 중 / 실패 | 에이전트 입력 |

---

## 🛠️ 실행 단계

### Step 1: 옵션 마스터 시트 생성

먼저 옵션값을 관리할 별도 시트를 만듭니다 (수정 편의성 ↑).

1. 시트 하단 `+` 클릭 → 새 시트 추가
2. 시트 이름: `옵션마스터`
3. 다음 데이터 입력:

```
A1: 매니저승인        B1: 클로징신호       C1: 실패사유
A2: 승인             B2: 강              C2: ① 남편 반대
A3: 반려             B3: 중              C3: ② 큰 지출에 대한 부담
A4: 대기             B4: 약              C4: ③ 우선순위 미흡
A5: 보류                                C5: ④ 결정 지연 (시간 필요)
                                       C6: ⑤ 효과에 대한 의구심
                                       C7: ⑥ 학원/방문 대안 고려
                                       C8: ⑦ 자녀 거부
                                       C9: ⑧ 가격 부담
                                       C10: ⑨ 기타

D1: 수업결과         E1: 재클로징결과
D2: 성공            E2: 성공
D3: 보류            E3: 진행 중
D4: 실패            E4: 실패
D5: 미진행
```

### Step 2: 에이전트 리스트 시트 생성

1. 새 시트 추가: `에이전트마스터`
2. 데이터 입력:

```
A1: 에이전트명         B1: 이메일             C1: 활성여부
A2: GiAR              B2: giar@lidia.com    C2: TRUE
A3: TINA              B3: tina@lidia.com    C3: TRUE
A4: LIDIA             B4: lidia@lidia.com   C4: TRUE
... (전체 10명+ 추가)
```

### Step 3: 교사 리스트 시트 생성

1. 새 시트 추가: `교사마스터`
2. 데이터 입력:

```
A1: 교사명            B1: 지역             C1: 이메일             D1: 활성여부
A2: Bu Rina          B2: Jakarta Pusat   B2: rina@bimble.com   D2: TRUE
A3: Bu Sari          B3: Jakarta Selatan B3: sari@bimble.com   D3: TRUE
... (전체 10명+ 추가)
```

### Step 4: 메인 트래커에 드롭다운 적용

#### 4-1. 매니저 승인 컬럼

1. 메인 트래커 시트로 이동
2. 매니저 승인 컬럼 전체 선택 (예: `H2:H1000`)
3. **데이터 → 데이터 확인** 메뉴
4. 다음 설정:

```
범위:        H2:H1000
기준:        드롭다운 (범위에서)
범위 선택:    =옵션마스터!A2:A5
고급 설정:
  ✅ 잘못된 데이터 거부
  ✅ 도움말 텍스트: "승인/반려/대기/보류 중 선택"
```

5. **저장**

#### 4-2. 클로징 신호 컬럼

```
범위:        L2:L1000 (실제 컬럼에 맞춰 조정)
범위 선택:    =옵션마스터!B2:B4
도움말:       "강/중/약 중 선택"
```

#### 4-3. 실패 사유 컬럼

```
범위:        F2:F1000
범위 선택:    =옵션마스터!C2:C10
도움말:       "보류 사유 선택"
```

#### 4-4. 에이전트 컬럼

```
범위:        C2:C1000
범위 선택:    =QUERY(에이전트마스터!A2:C, "SELECT A WHERE C = TRUE", 0)
            (단순 버전: =에이전트마스터!A2:A20)
도움말:       "에이전트 선택"
```

#### 4-5. 교사 컬럼

```
범위:        I2:I1000
범위 선택:    =QUERY(교사마스터!A2:D, "SELECT A WHERE D = TRUE", 0)
            (단순 버전: =교사마스터!A2:A20)
도움말:       "교사 선택"
```

#### 4-6. 수업 결과 + 재클로징 결과

```
수업 결과:
  범위:    M2:M1000
  범위 선택: =옵션마스터!D2:D5

재클로징 결과:
  범위:    O2:O1000
  범위 선택: =옵션마스터!E2:E4
```

## 🎨 입력 검증 추가 설정

### 날짜 컬럼 (신청일, 수업일 등)

1. 컬럼 선택 (예: `B2:B1000`)
2. **데이터 → 데이터 확인**
3. 설정:

```
기준:        날짜
세부 조건:    유효한 날짜
잘못된 데이터: 거부
도움말:       "날짜 형식: YYYY-MM-DD"
```

### 학부모 연락처 컬럼

```
기준:        커스텀 수식
수식:        =REGEXMATCH(D2, "^[0-9+\-\s]+$")
잘못된 데이터: 거부
도움말:       "숫자, +, - 만 입력 가능"
```

### 수업 횟수 (숫자만)

```
기준:        숫자
세부 조건:    크거나 같음 0
잘못된 데이터: 거부
```

## ⚠️ 자주 발생하는 실수

### 1. 범위에 헤더 포함
❌ `H1:H1000` (헤더 H1 포함 → 헤더에도 드롭다운 적용됨)
✅ `H2:H1000` (헤더 제외)

### 2. 범위가 너무 작음
❌ `H2:H100` (100건 초과 시 적용 안 됨)
✅ `H2:H1000` (충분히 크게)

### 3. "잘못된 데이터 거부" 미체크
- 기본값은 "경고만 표시"
- 거부 설정 안 하면 오타 그대로 입력됨

### 4. 옵션 마스터 수정 시 메인 시트 미반영
- 범위에서 직접 입력했다면 → 옵션마스터 수정해도 반영 안 됨
- "범위에서" 옵션으로 옵션마스터 참조해야 동기화됨

## ✅ 완료 확인

다음을 테스트하세요:

1. **드롭다운 작동**: 매니저 승인 셀 클릭 → 드롭다운 버튼 표시?
2. **거부 작동**: 셀에 임의 텍스트 입력 → 거부 알림?
3. **마스터 동기화**: 옵션마스터에 옵션 추가 → 메인 시트 드롭다운에 반영?
4. **에이전트 신규 추가**: 에이전트마스터에 추가 → 메인 시트 드롭다운에 반영?
