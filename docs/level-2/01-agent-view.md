# Level 2 - Agent View: 에이전트 전용 시트

> **목표**: 에이전트가 본인 케이스만 깔끔하게 관리
> **소요 시간**: 4시간 (시트 1개당 20분 × 10명+)
> **선행 작업**: 매니저 대시보드 완료

---

## 🛠️ 실행 단계

### Step 1: 에이전트별 시트 생성

#### 방법 A: 시트 하나에 에이전트 선택 (소규모)
- 한 시트에 드롭다운으로 에이전트 선택
- 데이터가 동적으로 바뀜
- 권한 분리 어려움

#### 방법 B: 에이전트마다 시트 1개 (대규모, 권장)
- 10개 시트 (GiAR, TINA, LIDIA, ...)
- 권한 분리 명확
- 본인만 본인 시트 접근

**대규모 팀 → 방법 B 권장**

---

### Step 2: 마스터 템플릿 시트 생성

먼저 템플릿 시트를 만들고, 복제해서 각 에이전트 시트로 만듭니다.

1. 새 시트 생성: `_AGENT_TEMPLATE`
2. 시트 색상: 회색 (템플릿임을 표시)
3. A1에 에이전트 이름 셀 추가:

```
A1: AGENT_NAME (수정 가능)
서식: 노란 배경 (강조)
```

다른 모든 수식에서 `A1`을 참조하여 에이전트 이름 사용.

---

### Step 3: 상단 인사말 + KPI

#### 3-1. 인사말

```
B1: =CONCATENATE("👋 ", A1, "님의 오늘 - ", TEXT(TODAY(), "yyyy-mm-dd (ddd)"))
서식: 폰트 16, 굵게, 배경 #4285F4, 글자 흰색
```

#### 3-2. KPI 카드 4개

```
A5: =COUNTIFS(메인트래커!C:C, $A$1,
              메인트래커!H:H, "승인",
              메인트래커!M:M, "")
B5: "📋 진행 중"

C5: =COUNTIFS(메인트래커!C:C, $A$1,
              메인트래커!M:M, "보류")
       (재클로징 대기 = 보류 처리된 케이스)
D5: "⏰ 재클로징 대기"

E5: =COUNTIFS(메인트래커!C:C, $A$1,
              메인트래커!M:M, "성공",
              메인트래커!J:J, ">="&EOMONTH(TODAY(),-1)+1)
F5: "✅ 이번 달 성공"

G5: =COUNTIFS(메인트래커!C:C, $A$1,
              메인트래커!M:M, "성공")
H5: "💰 누적 성공"
```

### Step 4: 오늘 액션 필요 (D-Day 임박)

```
A10: "🚨 오늘 액션 필요"
서식: 빨강 배경, 흰 글자, 폰트 14
```

```excel
A11:
=QUERY(메인트래커!A2:Z1000,
  "SELECT A, D, E, F, Q, M
   WHERE C = '" & A1 & "'
     AND (Q CONTAINS 'D-1'
       OR Q CONTAINS 'D-2'
       OR Q = '마감')
   ORDER BY Q ASC
   LABEL A 'NO', D '학부모', E '자녀', F '사유', Q 'D-Day', M '상태'", 0)
```

#### 4-1. 액션 가이드 컬럼 추가

수식 옆에 사유별 대응 가이드 자동 표시:

```excel
H11 (Action 추천):
=IFERROR(
  VLOOKUP(LEFT(F11, 1),
          액션가이드!A:B,
          2,
          FALSE),
  "")
```

`액션가이드` 시트 생성:

```
A1: 사유번호    B1: 추천 액션
A2: ①         B2: 자녀 반응 영상 확보 + 엄마 즉시 공유
A3: ②         B3: 분할 결제 또는 단기 체험 제안
A4: ③         B4: 자녀 성장 시각화 자료 제시
A5: ④         B5: 데드라인 명시 + 조건 제시
A6: ⑤         B6: 구체적 의심 포인트 시연 + 데이터
A7: ⑥         B7: 1:1 vs 그룹의 차이 사례 제시
A8: ⑦         B8: 자녀 흥미 끄는 콘텐츠 추천
A9: ⑧         B9: 가성비 분석 자료 + 할인 옵션
A10: ⑨        B10: 매니저 상담 권장
```

### Step 5: 진행 중인 케이스 리스트

```
A20: "📝 진행 중인 케이스"
서식: 파랑 배경, 흰 글자, 폰트 14
```

```excel
A21:
=QUERY(메인트래커!A2:Z1000,
  "SELECT A, D, E, J, I, M, Q
   WHERE C = '" & A1 & "'
     AND H = '승인'
     AND M <> '성공'
     AND M <> '실패'
   ORDER BY Q ASC
   LABEL A 'NO', D '학부모', E '자녀', J '수업일', I '교사', M '결과', Q 'D-Day'", 0)
```

### Step 6: 본인 성과 요약

```
A40: "📊 내 이번 달 성과"
```

#### 6-1. 텍스트 요약

```excel
A41:
=CONCATENATE(
  "신청: ",
  COUNTIFS(메인트래커!C:C, $A$1,
           메인트래커!B:B, ">="&EOMONTH(TODAY(),-1)+1),
  "건 / 성공: ",
  COUNTIFS(메인트래커!C:C, $A$1,
           메인트래커!M:M, "성공",
           메인트래커!J:J, ">="&EOMONTH(TODAY(),-1)+1),
  "건 / 진행: ",
  COUNTIFS(메인트래커!C:C, $A$1,
           메인트래커!H:H, "승인",
           메인트래커!M:M, "")
)
```

#### 6-2. 성공률 + 전월 대비

```excel

TEXT(
  COUNTIFS(메인트래커!C:C, $A$1, 메인트래커!M:M, "성공",

" (전월 " &

  COUNTIFS(메인트래커!C:C, $A$1, 메인트래커!M:M, "성공",
           메인트래커!J:J, ">="&EOMONTH(TODAY(),-2)+1,
           메인트래커!J:J, "<"&EOMONTH(TODAY(),-1)+1) /
  COUNTIFS(메인트래커!C:C, $A$1,
           메인트래커!B:B, ">="&EOMONTH(TODAY(),-2)+1,
           메인트래커!B:B, "<"&EOMONTH(TODAY(),-1)+1),
  "0.0%"
) & ")"
```

### Step 7: 인사이트 자동 생성

본인 데이터 기반 인사이트:

```excel
A50: "💡 인사이트"

A51 (가장 많은 실패 사유):
=CONCATENATE(
  "가장 많은 실패 사유: ",
  INDEX(옵션마스터!C:C,
    MATCH(
      MAX(
        IF(메인트래커!C:C=$A$1,
           COUNTIF(메인트래커!F:F, 옵션마스터!C2:C10),
           0)),
      COUNTIF(메인트래커!F:F, 옵션마스터!C2:C10),
      0) + 1),
  " (",
  MAX(
    IF(메인트래커!C:C=$A$1,
       COUNTIF(메인트래커!F:F, 옵션마스터!C2:C10),
       0)),
  "건)"
)
```

```excel
A52 (추천 액션):
=CONCATENATE(
  "추천: ",
  VLOOKUP(
    LEFT(
      INDEX(옵션마스터!C:C,
        MATCH(
          MAX(...),
          COUNTIF(메인트래커!F:F, 옵션마스터!C2:C10),
          0) + 1),
      1),
    인사이트가이드!A:B,
    2,
    FALSE
  )
)
```

`인사이트가이드` 시트 생성:

```
A1: 사유    B1: 추천 전략
A2: ①      B2: 가족 단위 어필 전략 강화 - 남편 대상 콘텐츠 준비
A3: ②      B3: 분할 결제 옵션 적극 안내
A4: ③      B4: 자녀 성장 시각화에 집중
... (각 사유별)
```

### Step 8: 시트 복제 (각 에이전트별)

#### 8-1. 마스터 템플릿 복제

1. `_AGENT_TEMPLATE` 시트 탭 우클릭
2. **복제**
3. 새 이름: `GiAR` (에이전트 이름)
4. A1 셀에 "GiAR" 입력 → 모든 수식이 자동으로 GiAR 데이터로 갱신

#### 8-2. 모든 에이전트 반복

10명+ 에이전트 모두 반복:
- `GiAR`
- `TINA`
- `LIDIA`
- ... (전체)

#### 8-3. 시트 색상 통일

```
색상 코드:
GiAR:   파랑 (#4285F4)
TINA:   초록 (#34A853)
LIDIA:  주황 (#FF9800)
...

전체 에이전트 시트는 한 그룹으로 색상 분리.
```

### Step 9: 권한 설정

#### 9-1. 시트 보호

각 에이전트 시트마다:

1. 시트 탭 우클릭 → **시트 보호**
2. 설정:

```
설명:        [에이전트명] 전용 시트
권한:        일부 사용자만 편집 가능
편집자:      해당 에이전트 + 매니저 + 본부장
```

#### 9-2. 시트 숨김

다른 에이전트 시트는 본인에게 숨김 처리 어려움 (Google Sheets 제약).

**대안**:
- 시트 탭 그룹화 (색상으로 구분)
- 명명 규칙으로 빠른 탐색 (예: `[A] GiAR`, `[A] TINA`)
- 첫 번째 시트로 `매니저대시보드` 배치 → 일반 사용자 첫 화면

#### 9-3. 시트 URL 직접 공유

각 에이전트에게 본인 시트 URL 직접 공유:

```
GiAR 시트 URL:
https://docs.google.com/spreadsheets/d/{ID}/edit#gid={SHEET_ID}

이 URL을 GiAR에게 이메일 또는 왓츠앱으로 공유.
GiAR는 이 URL 클릭 시 바로 본인 시트로 이동.
```

## 🎨 디자인 가이드

### 시트 첫인상 (3초 룰)

에이전트가 시트 열고 3초 안에 다음 파악:

1. ✅ "오늘 뭐 해야 하지?" → 상단 인사말 + 액션 필요 섹션
2. ✅ "내 케이스 현황?" → KPI 카드
3. ✅ "잘 하고 있나?" → 성과 요약

### 색상 의미 통일

```
빨강:    긴급, 액션 필요
노랑:    주의, 대기
초록:    완료, 성공
파랑:    정보, 일반
회색:    참고, 비활성
```

### 폰트 위계

```
인사말:           18pt 굵게
섹션 제목:        14pt 굵게
KPI 숫자:         28pt 굵게
KPI 라벨:         11pt
본문:            10pt
주석:            9pt 이탤릭
```

## 🔧 고급 기능

### 1. 본인 시트 빠른 접근 북마크

각 에이전트 브라우저 북마크:
```
즐겨찾기 → "내 Lidia 시트"
URL: 본인 시트 URL
```

### 2. 모바일 최적화

Google Sheets 모바일 앱 사용 시:
- 컬럼 수 줄이기 (가로 스크롤 최소화)
- 폰트 크기 12pt 이상
- KPI 카드는 세로 배치 추천

### 3. 동료 비교 (선택)

본인 시트에 다른 에이전트 성과 비교:

```excel
=QUERY(에이전트별성과!A2:D20,
  "SELECT A, D
   WHERE A = '" & A1 & "' OR A IN
     (SELECT TOP 3 A ORDER BY D DESC)", 0)
```

→ 본인 + 상위 3명 표시 (경쟁심 자극)

### 4. 알림 설정

본인 케이스 상태 변경 시 이메일 알림:

1. **도구 → 알림 규칙**
2. 변경 사항: "셀이 변경됨"
3. 범위: 본인 시트
4. 알림 빈도: 즉시

→ 매니저가 본인 케이스 승인하면 즉시 이메일.

## ⚠️ 자주 발생하는 실수

### 1. A1 셀 미입력
**증상**: 모든 수식이 빈 결과
**원인**: A1에 에이전트 이름 없음
**해결**: 시트 복제 후 A1에 정확한 이름 입력

### 2. 에이전트 이름 표기 차이
**증상**: 본인 케이스가 안 보임
**원인**: 메인 트래커는 "GiAR", 본인 시트 A1은 "Giar"
**해결**: 대소문자/공백 정확히 일치

### 3. QUERY 수식 큰따옴표 오류
**증상**: `#ERROR!`
**원인**: 수식 내 `'` 와 `"` 혼동
**해결**:
```
❌ "WHERE C = 'A1'"  (A1을 텍스트로 처리)
✅ "WHERE C = '" & A1 & "'"  (A1 셀 값 참조)
```

### 4. 시트 복제 시 수식 깨짐
**증상**: 새 시트에 #REF 오류
**원인**: 시트명에 특수문자/공백
**해결**: 시트명을 영문/숫자만 사용

## ✅ 완료 확인

각 에이전트 시트에 대해:

1. **본인 이름 확인**: A1에 정확한 이름 표시?
2. **KPI 카드**: 본인 케이스 카운트 정확?
3. **액션 필요**: 본인 D-Day 임박 케이스만 표시?
4. **진행 중**: 본인 진행 케이스만 표시?
5. **다른 에이전트 데이터 노출**: 다른 사람 데이터 안 보임?
6. **권한**: 다른 에이전트가 본인 시트 접근 안 됨?

모두 정상이면 **[Step 3: 교사 전용 시트](./02-teacher-view.md)**로 이동!
