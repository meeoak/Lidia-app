## 🛠️ 실행 단계

### Step 1: 마스터 템플릿 생성

1. 새 시트: `_TEACHER_TEMPLATE`
2. A1 셀: TEACHER_NAME

각 에이전트 시트와 동일한 방식으로 시작.

---

### Step 2: 상단 인사말 + KPI

#### 2-1. 인사말

```excel
B1: =CONCATENATE("👩‍🏫 ", A1, "님의 오늘 - ", TEXT(TODAY(), "yyyy-mm-dd (ddd)"))
서식: 폰트 16, 굵게, 배경 #34A853 (초록), 글자 흰색
```

#### 2-2. KPI 카드

```excel
A5 (오늘 수업):
=COUNTIFS(메인트래커!I:I, $A$1,
          메인트래커!J:J, TODAY())
B5: "📅 오늘 수업"

C5 (이번 주 수업):
=COUNTIFS(메인트래커!I:I, $A$1,
          메인트래커!J:J, ">="&TODAY()-WEEKDAY(TODAY(),2)+1,
          메인트래커!J:J, "<="&TODAY()-WEEKDAY(TODAY(),2)+7)
D5: "📆 이번 주 수업"

E5 (누적 수업):
=COUNTIFS(메인트래커!I:I, $A$1,
          메인트래커!M:M, "<>", "")
       (수업 결과가 입력된 모든 케이스)
F5: "📋 누적 수업"

G5 (평점 - Level 3에서 자동 수집):
=IFERROR(AVERAGEIFS(평점!C:C, 평점!B:B, $A$1), "-")
H5: "⭐ 평점 (5점)"
```

### Step 3: 오늘 일정 (가장 중요!)

```
A10: "📅 오늘 일정"
서식: 빨강 배경, 흰 글자, 폰트 14
```

#### 3-1. 기본 일정 정보

```excel
A11:
=QUERY(메인트래커!A2:Z1000,
  "SELECT K, D, E, R, F, U
   WHERE I = '" & A1 & "'
     AND J = DATE '" & TEXT(TODAY(), "yyyy-mm-dd") & "'
   ORDER BY K ASC
   LABEL K '시간', D '학부모', E '자녀', R '주소', F '보류사유', U '메모'", 0)
```

**주의**: K=시간, R=주소, U=메모 컬럼은 메인 트래커에 추가되어야 함.

#### 3-2. 보류 사유별 수업 전략 자동 표시

기존 액션가이드를 교사용으로 확장:

`교사가이드` 시트 생성:

```
A1: 사유   B1: 수업 전략 (교사)
A2: ①    B2: 1) 자녀의 반응 영상 확보 (수업 중 자연스럽게)
              2) 엄마에게 즉시 영상 공유 + 남편에게도 보여달라 요청
              3) 학습보다는 '즐거움' 강조
A3: ②    B3: 1) 분할 결제/체험 옵션 제안
              2) 비용 대비 효과 시각화
              3) 가성비 자료 미리 준비
A4: ③    B4: 1) 자녀의 성장 포인트 적극 발견 및 칭찬
              2) "1주만 더 보면 확실히 알 수 있다" 메시지
              3) 다음 수업 강한 예고
A5: ④    B5: 1) 의사 결정 데드라인 명시 (이번 주 안)
              2) 한정 조건 제시 (이번 달 특가)
              3) 자녀의 호응 강조
A6: ⑤    B6: 1) 구체적 의심 포인트 직접 시연
              2) 데이터 기반 효과 자료 준비
              3) 비교 가능한 케이스 스터디 제시
A7: ⑥    B7: 1) 1:1 vs 그룹의 차이 명확히 시연
              2) 자녀 맞춤 학습 사례 강조
              3) 학원 대비 장점 데이터
A8: ⑦    B8: 1) 자녀의 좋아하는 캐릭터/주제 활용
              2) 게임 요소 도입
              3) 짧고 강한 호기심 자극
A9: ⑧    B9: 1) 매니저 상담 권유
              2) 회사 차원 할인 안내
              3) 가족 단위 패키지 옵션
A10: ⑨   B10: 1) 매니저에게 즉시 인계
              2) 구체적 거부 사유 파악
              3) 다음 방향 제안
```

#### 3-3. 수업 전략 자동 매칭

```excel
H11 (수업 전략 컬럼):
=ARRAYFORMULA(
  IFERROR(
    VLOOKUP(LEFT(F11:F20, 1), 교사가이드!A:B, 2, FALSE),
    ""
  )
)
```

### Step 4: 이번 주 일정

```
A30: "📆 이번 주 일정"
서식: 파랑 배경, 흰 글자, 폰트 14
```

```excel
A31:
=QUERY(메인트래커!A2:Z1000,
  "SELECT J, K, D, E, M
   WHERE I = '" & A1 & "'
     AND J >= DATE '" & TEXT(TODAY()-WEEKDAY(TODAY(),2)+1, "yyyy-mm-dd") & "'
     AND J <= DATE '" & TEXT(TODAY()-WEEKDAY(TODAY(),2)+7, "yyyy-mm-dd") & "'
   ORDER BY J ASC, K ASC
   LABEL J '날짜', K '시간', D '학부모', E '자녀', M '상태'", 0)
```

#### 4-1. 요일 표시 추가

날짜만 보면 "5/19"인데 무슨 요일인지 헷갈림. 요일 자동 추가:

```excel
별도 컬럼 추가 (예: A31 옆 B31):
=ARRAYFORMULA(IF(ROW(A31:A50)>ROW(A31), TEXT(A31:A50, "ddd"), "요일"))
```

또는 QUERY에서 직접:

```excel
=ARRAYFORMULA(
  IFERROR(
    VLOOKUP(
      QUERY(메인트래커!A2:Z1000, "SELECT J ..."),
      ...
    ),
    "")
)
```

## 🎨 모바일 우선 디자인

**중요**: 교사는 수업 현장에서 모바일로 시트 확인하는 경우가 많음.

### 모바일 최적화 원칙

1. **세로 스크롤만**: 가로 스크롤 최소화
2. **큰 폰트**: 12pt 이상
3. **간결한 정보**: 핵심만 표시
4. **터치 친화**: 셀 높이 40px 이상

### 모바일 전용 섹션 (선택)

별도 시트 `[모바일] 교사명` 생성:

## 🔧 고급 기능

### 1. 실시간 학부모 메모

수업 중 학부모에게 들은 정보를 즉시 메모:

```
[메모 시트] 추가
A1: 날짜  B1: 학부모  C1: 메모

수업 중 음성 입력 또는 빠른 텍스트 입력.
```

### 2. 수업 자료 링크

각 사유별 사용할 자료 자동 링크:

```excel
=VLOOKUP(LEFT(F11, 1), 수업자료!A:C, 2, FALSE)
→ ① 남편 반대용 자료 PDF 링크 자동 표시
```

### 3. 이전 수업 결과 자동 표시

같은 학부모의 이전 수업 결과:

```excel
=QUERY(메인트래커!A2:Z1000,
  "SELECT J, M, N
   WHERE D = '" & D11 & "'
     AND J < DATE '" & TEXT(TODAY(), "yyyy-mm-dd") & "'
   ORDER BY J DESC
   LIMIT 3", 0)
```

→ 같은 학부모와의 최근 3회 수업 결과 표시.

### 4. 교사 간 인계

휴가/병가 시 다른 교사에게 인계:

```
인계 시트 추가:
- 인계할 케이스 선택
- 인계받을 교사 선택
- 인계 메모
→ 자동으로 메인 트래커 교사 컬럼 변경
```

## ⚠️ 자주 발생하는 실수

### 1. 학부모 정보 노출
**문제**: Bu Rina 시트에서 다른 교사가 담당하는 학부모 정보 노출
**해결**: QUERY 조건에 `I = '" & A1 & "'` 정확히 적용 + 시트 권한 분리

### 2. 시간대 충돌
**증상**: 같은 시간 두 수업 표시
**해결**: 조건부 서식으로 충돌 케이스 빨강 강조

### 3. 모바일에서 수식 깨짐
**증상**: 모바일에서 #REF 또는 빈 셀
**원인**: 모바일 앱이 일부 수식 지원 안 함
**해결**: ARRAYFORMULA 대신 단순 셀 수식 사용

### 4. 학부모 메모 길이 초과
**증상**: 셀 한 칸에 모든 메모 → 가독성 ↓
**해결**: 별도 메모 시트 + 링크로 연결

## ✅ 완료 확인

각 교사 시트에 대해:

1. **본인 이름**: A1에 정확한 이름?
2. **오늘 수업**: 본인 오늘 수업만 표시?
3. **보류 사유**: 자동 표시?
4. **수업 전략**: 사유별 자동 매칭?
5. **이번 주 일정**: 일주일치 정확히 표시?
6. **다른 교사 데이터**: 안 보임?
7. **모바일 가독성**: 폰에서도 읽기 좋음?

모두 정상이면 **[Step 4: 입력 폼 분리](./04-input-forms.md)**로 이동!
