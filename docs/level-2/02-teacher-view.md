# Level 2 - Teacher View: 교사 전용 시트

> **목표**: 교사가 수업 전 5분 안에 모든 정보 확인
> **소요 시간**: 4시간 (시트 1개당 20분 × 10명+)
> **선행 작업**: 매니저 대시보드 완료

---

## 📖 교사가 시트 읽는 법 (먼저 읽어주세요)

이 시트는 영업팀(에이전트·매니저)이 함께 쓰는 시트라 **영업 용어**가 섞여 있어요.
교사가 자주 보는 항목만 쉬운 말로 정리했습니다.

### 1) 시트에서 교사가 보는 곳 (3군데만)

| 영역 | 무엇을 보나요? | 언제 보나요? |
|---|---|---|
| 📅 **오늘 수업** | 오늘 만날 학부모·자녀·시간·장소 | 매일 아침 |
| 💡 **수업 전략** | 학부모 망설임 이유에 맞는 추천 전략 | 수업 가기 직전 |
| ✍️ **수업 후 입력** | 수업이 끝난 뒤 결과 입력 | 수업 종료 후 24시간 안에 |

> 나머지 영역(매니저 승인, 신청일, 누적 통계 등)은 **읽기만 하면 되고 입력은 안 합니다**.

### 2) 자주 나오는 용어 — 교사용 번역

| 시트에 적힌 말 | 쉽게 풀면 | 교사 입력 여부 |
|---|---|---|
| 실패 사유 / 보류 사유 | 학부모가 **망설이는 이유** (① 남편 반대 등) | ❌ (에이전트가 입력) |
| 클로징 신호 (강/중/약) | 수업 후 학부모의 **계약 의향** | ✅ 교사가 판단해 선택 |
| 수업 결과 = 성공 | 학부모가 **계약 의사 확인** | ✅ |
| 수업 결과 = 보류 | **재상담 필요** (긍정적이지만 결정 미룸) | ✅ |
| 수업 결과 = 실패 | 학부모가 **포기 의사**를 명확히 밝힘 | ✅ |
| 수업 결과 = 미진행 | 학부모/자녀 부재 등으로 **수업 자체가 안 됨** | ✅ |
| 재클로징 | 에이전트가 **다시 학부모를 만나 설득**하는 단계 | ❌ |
| D-Day / D-3 | 재상담까지 **며칠 남았는지** (D-3 = 3일 남음) | ❌ (자동 계산) |
| 의사결정자 | 가정에서 **계약 결정을 내리는 사람** (엄마/아빠/공동) | ❌ |
| Agent | 학부모를 처음 만난 **영업 담당자** | ❌ |

전체 용어 매핑은 [`docs/templates/teacher-glossary.csv`](../templates/teacher-glossary.csv) 참고.

### 3) 수업 전 5분 체크리스트

```
□ 1. 오늘 수업 시간·장소 확인
□ 2. 학부모 망설임 이유 확인 (예: "① 남편 반대")
□ 3. 망설임 이유에 맞는 수업 전략 1줄 읽기
□ 4. 학부모 메모 확인 (예: "남편은 학원 선호")
□ 5. Agent 연락처 저장 (변경 사항 있을 때 연락)
```

### 4) 수업 후 입력 — 4가지만 정확히

```
1. 수업 결과   → 성공 / 보류 / 실패 / 미진행
2. 계약 의향   → 강 / 중 / 약  (학부모 분위기 기준)
3. 자녀 반응   → 매우 적극적 / 보통 / 소극적
4. 학부모 말씀 → 학부모가 한 말을 1-2 문장으로 그대로 적기
```

> ⚠️ 4번(학부모 말씀)이 **가장 중요**합니다. 에이전트가 재상담할 때 그대로 활용해요.

### Step 3: 오늘 일정 (가장 중요!)

```
A10: "📅 오늘 일정"
서식: 빨강 배경, 흰 글자, 폰트 14
```

#### 3-1. 기본 일정 정보

```excel
A11:
=QUERY(메인트래커!A2:Z1000,
  "SELECT K, D, E, R, F, U
   WHERE I = '" & A1 & "'
     AND J = DATE '" & TEXT(TODAY(), "yyyy-mm-dd") & "'
   ORDER BY K ASC
   LABEL K '수업 시간', D '학부모', E '자녀', R '지역', F '학부모 망설임 이유', U '학부모 메모'", 0)
```

**주의**: K=시간, R=주소, U=메모 컬럼은 메인 트래커에 추가되어야 함.

> 💡 라벨이 길어도 헷갈리는 것보다 낫습니다. "보류사유"보다 "학부모 망설임 이유"가 교사가 한 번에 이해돼요.

#### 3-2. 보류 사유별 수업 전략 자동 표시

기존 액션가이드를 교사용으로 확장:

`교사가이드` 시트 생성 — 사유 기호(①~⑨)와 함께 **사유 설명**을 같이 적어 교사가 바로 이해할 수 있게 합니다:

```
A1: 사유 기호  B1: 사유 설명              C1: 수업 전략 (교사용)

A2: ①         B2: 남편이 반대함          C2: 1) 자녀의 즐거워하는 모습을 영상으로 담기 (수업 중 자연스럽게)
                                            2) 엄마에게 즉시 영상 공유 → 남편에게 보여달라고 요청
                                            3) "학습"보다 "자녀가 즐거워한다"를 강조

A3: ②         B3: 큰 지출이 부담스러움    C3: 1) 분할 결제·체험 옵션이 있다고 안내
                                            2) "이 정도 비용으로 이런 효과" 시각화
                                            3) 가성비 자료를 미리 준비해 보여주기

A4: ③         B4: 우선순위가 낮음         C4: 1) 자녀의 성장 포인트를 적극 발견하고 칭찬
                                            2) "1주만 더 보시면 확실히 알 수 있어요" 메시지 전달
                                            3) 다음 수업을 강하게 예고 ("다음엔 ○○해볼 거예요")

A5: ④         B5: 결정을 미루는 중        C5: 1) 의사결정 데드라인 명시 ("이번 주 안에 결정하시면…")
                                            2) 한정 조건 제시 (이번 달 특가 등)
                                            3) 자녀의 호응을 적극 강조

A6: ⑤         B6: 효과에 의구심을 가짐    C6: 1) 학부모가 의심하는 부분을 직접 시연
                                            2) 데이터·자료로 효과를 보여주기
                                            3) 비슷한 케이스의 성과 스터디를 제시

A7: ⑥         B7: 학원·방문수업 대안 고려 C7: 1) 1:1 수업과 그룹 수업의 차이를 명확히 시연
                                            2) 자녀 맞춤 학습 사례를 강조
                                            3) 학원 대비 장점을 데이터로 제시

A8: ⑦         B8: 자녀가 거부함           C8: 1) 자녀가 좋아하는 캐릭터·주제를 활용
                                            2) 게임 요소를 도입
                                            3) 짧고 강한 호기심 자극으로 시작

A9: ⑧         B9: 가격이 부담스러움       C9: 1) 매니저 상담을 권유
                                            2) 회사 차원의 할인이 있다고 안내
                                            3) 가족 단위 패키지 옵션을 제시

A10: ⑨        B10: 기타 (위에 없는 이유)  C10: 1) 매니저에게 즉시 인계
                                             2) 구체적인 거부 사유를 파악
                                             3) 다음 방향을 제안
```

> 💡 **왜 사유 설명 컬럼(B)을 따로 두나요?**
> 교사가 ① 같은 기호만 보면 매번 외워야 하는데, 옆에 "남편이 반대함"이라고 같이 보여주면 0초 안에 이해 가능합니다.

#### 3-3. 수업 전략 자동 매칭

`교사가이드` 시트는 `A=사유 기호 / B=사유 설명 / C=수업 전략` 3개 컬럼이므로 전략 컬럼은 **3번째** 컬럼입니다:

```excel
H11 (수업 전략 컬럼):
=ARRAYFORMULA(
  IFERROR(
    VLOOKUP(LEFT(F11:F20, 1), 교사가이드!A:C, 3, FALSE),
    ""
  )
)
```

> 💡 사유 설명도 같이 보여주고 싶다면 G11에 동일 수식으로 2번째 컬럼을 VLOOKUP:
> `=ARRAYFORMULA(IFERROR(VLOOKUP(LEFT(F11:F20, 1), 교사가이드!A:C, 2, FALSE), ""))`

#### 4-1. 요일 표시 추가

날짜만 보면 "5/19"인데 무슨 요일인지 헷갈림. 요일 자동 추가:

```excel
별도 컬럼 추가 (예: A31 옆 B31):
=ARRAYFORMULA(IF(ROW(A31:A50)>ROW(A31), TEXT(A31:A50, "ddd"), "요일"))
```

또는 QUERY에서 직접:

```excel
=ARRAYFORMULA(
  IFERROR(
    VLOOKUP(
      QUERY(메인트래커!A2:Z1000, "SELECT J ..."),
      ...
    ),
    "")
)
```

```excel
  COUNTIFS(메인트래커!I:I, $A$1, 메인트래커!M:M, "성공",
           메인트래커!J:J, ">="&EOMONTH(TODAY(),-1)+1) /
  COUNTIFS(메인트래커!I:I, $A$1,
           메인트래커!J:J, ">="&EOMONTH(TODAY(),-1)+1),
  "0.0%")

A93 (가장 자주 만난 사유):
="가장 자주 만난 보류 사유: ..." (에이전트 시트와 유사)
```

## 🔧 고급 기능

### 1. 실시간 학부모 메모

수업 중 학부모에게 들은 정보를 즉시 메모:

```
[메모 시트] 추가
A1: 날짜  B1: 학부모  C1: 메모

수업 중 음성 입력 또는 빠른 텍스트 입력.
```

### 2. 수업 자료 링크

각 사유별 사용할 자료 자동 링크:

```excel
=VLOOKUP(LEFT(F11, 1), 수업자료!A:C, 2, FALSE)
→ ① 남편 반대용 자료 PDF 링크 자동 표시
```

### 3. 이전 수업 결과 자동 표시

같은 학부모의 이전 수업 결과:

```excel
=QUERY(메인트래커!A2:Z1000,
  "SELECT J, M, N
   WHERE D = '" & D11 & "'
     AND J < DATE '" & TEXT(TODAY(), "yyyy-mm-dd") & "'
   ORDER BY J DESC
   LIMIT 3", 0)
```

→ 같은 학부모와의 최근 3회 수업 결과 표시.

### 4. 교사 간 인계

휴가/병가 시 다른 교사에게 인계:

```
인계 시트 추가:
- 인계할 케이스 선택
- 인계받을 교사 선택
- 인계 메모
→ 자동으로 메인 트래커 교사 컬럼 변경
```

## ⚠️ 자주 발생하는 실수

### 1. 학부모 정보 노출
**문제**: Bu Rina 시트에서 다른 교사가 담당하는 학부모 정보 노출
**해결**: QUERY 조건에 `I = '" & A1 & "'` 정확히 적용 + 시트 권한 분리

### 2. 시간대 충돌
**증상**: 같은 시간 두 수업 표시
**해결**: 조건부 서식으로 충돌 케이스 빨강 강조

### 3. 모바일에서 수식 깨짐
**증상**: 모바일에서 #REF 또는 빈 셀
**원인**: 모바일 앱이 일부 수식 지원 안 함
**해결**: ARRAYFORMULA 대신 단순 셀 수식 사용

### 4. 학부모 메모 길이 초과
**증상**: 셀 한 칸에 모든 메모 → 가독성 ↓
**해결**: 별도 메모 시트 + 링크로 연결
