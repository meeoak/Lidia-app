# Level 1 - Step 5: 시트 보호 설정

> **목표**: 실수로 인한 데이터 손실 방지
> **소요 시간**: 15분
> **선행 작업**: Step 1-4 완료

---

## 🎯 왜 필요한가?

### 위험 시나리오
- 에이전트 A가 실수로 운영가이드 시트의 셀 삭제 → 매니저 발견까지 모름
- 교사 B가 다른 교사 케이스를 실수로 수정 → 데이터 손상
- 누군가 D-Day 수식을 일반 텍스트로 덮어씀 → 자동화 깨짐

### 보호 설정 후
- 권한 없는 사용자는 편집 시도 시 자동 차단
- 수식 컬럼은 매니저만 수정 가능
- 운영 가이드는 모든 사용자 읽기 전용

## 🛠️ 실행 단계

### Step 1: 운영 가이드 시트 보호

가장 중요한 보호 (참조용 문서이므로 절대 수정 안 되어야 함).

1. `운영가이드` 시트 탭 우클릭
2. **시트 보호** 선택
3. 설정:

```
설명:        운영 가이드 (매니저만 수정 가능)
범위:        시트 전체
권한 설정:
  ✅ 일부 사용자만 편집 가능
  편집자 추가:
    - 본부장 이메일
    - 매니저 이메일
```

4. **완료**

#### 1-1. 경고만 표시할 경우 (덜 엄격)

```
권한 설정:
  ⚠️ 이 범위 수정 시 경고 표시
```

매니저가 일부러 수정해야 할 때 알림만 뜨고 진행 가능.

---

### Step 2: 옵션 마스터 시트 보호

```
시트:           옵션마스터
설명:           옵션 마스터 (매니저만 관리)
권한:           일부 사용자만 편집 가능
편집자:         본부장, 매니저
```

마찬가지로 에이전트/교사 마스터 시트도 보호.

---

### Step 3: 메인 트래커 헤더 보호

헤더 행이 실수로 수정/삭제되면 모든 수식이 깨짐.

1. 메인 트래커 시트에서 1행 전체 선택 (행 번호 `1` 클릭)
2. **데이터 → 보호된 시트 및 범위**
3. 사이드바에서 **범위 추가**
4. 설정:

```
설명:           헤더 행 (수정 금지)
범위:           메인트래커!A1:Z1
권한:           일부 사용자만 편집 가능
편집자:         본부장, 매니저
```

---

### Step 4: D-Day 수식 컬럼 보호

수식이 들어있는 컬럼은 일반 사용자가 덮어쓰지 못하도록 보호.

```
설명:           D-Day 수식 (수정 금지)
범위:           메인트래커!Q2:Q1000
권한:           본부장만 편집 가능
경고:           "이 셀에는 자동 계산 수식이 있습니다. 변경하지 마세요."
```

---

### Step 5: 매니저 승인 컬럼 보호

에이전트나 교사가 본인 케이스를 임의로 "승인" 처리하지 못하도록.

```
설명:           매니저 승인 (매니저만 결정)
범위:           메인트래커!H2:H1000
권한:           본부장, 매니저
```

---

### Step 6: 교사 배정 컬럼 보호

```
설명:           교사 배정 (매니저만 결정)
범위:           메인트래커!I2:I1000
권한:           본부장, 매니저
```

---

### Step 7: 완료된 케이스 보호 (선택)

수업 결과가 입력된 케이스는 사후 변경 방지.

**방법**: 조건부 보호 (조금 복잡)

1. **데이터 → 보호된 시트 및 범위**
2. 새 범위 추가:

```
설명:           완료 케이스 보호
범위:           메인트래커!A2:Z1000
권한:           일부 사용자만 편집 가능
편집자:         본부장만
```

→ 너무 엄격하면 운영 어려움. **권장 안 함** (Level 3에서 Apps Script로 처리)

---

### Step 8: 매니저 대시보드 보호 (Level 2 시)

Level 2 매니저 대시보드 구축 후:

```
시트:           매니저대시보드
범위:           시트 전체
권한:           본부장, 매니저만 편집
경고:           "대시보드 데이터는 자동 계산됩니다. 직접 수정하지 마세요."
```

## 👥 권한 관리 베스트 프랙티스

### 1. 권한 그룹 활용

개별 이메일 추가보다 Google Workspace 그룹 사용:

```
managers@lidia.com    → 매니저 + 본부장
agents@lidia.com      → 모든 에이전트
teachers@bimble.com   → 모든 교사
```

새 매니저 추가 시 → 그룹에만 추가 → 모든 시트 권한 자동 적용

### 2. 시트 공유 권한과 분리

```
시트 자체 공유:    조직 전체 (편집자)
보호 설정:        각 영역별 세부 권한
```

- 시트는 모두에게 열려 있음
- 특정 영역만 특정 사람이 편집 가능

### 3. 알림 설정

보호된 범위 편집 시 알림 받기:

1. 도구 → 알림 규칙
2. "변경 사항 발생" → 즉시 알림
3. 본부장 이메일로 발송

매니저 승인 컬럼이 변경될 때마다 본부장 이메일.

## 🚨 보호 우회 방법 (참고)

악의적인 사용자가 우회할 수 있는 방법 (방어 위해 알아두기):

### 1. 시트 사본 만들기
- 사용자가 사본 만들면 본인 사본은 자유롭게 수정 가능
- **방어**: 시트 공유 시 "사본 만들기 비활성화" 설정

### 2. 다운로드
- 엑셀로 다운로드 가능
- **방어**: 공유 설정에서 "다운로드/인쇄/복사 비활성화"

### 3. 셀 잠금 해제 (편집자만 가능)
- 편집자 권한이 있으면 본인이 보호 해제 가능
- **방어**: 보호 설정 변경 권한을 본부장만 부여

### 선택 (필요 시)

## ⚠️ 자주 발생하는 실수

### 1. 본인을 편집자에서 빠뜨림
**증상**: 본부장이 본인 시트인데 수정 못함
**해결**: 권한 설정 시 본인 이메일도 명시적으로 추가

### 2. 그룹 권한 vs 개별 권한 충돌
**증상**: 그룹에 있는데 편집 안 됨
**원인**: 개별 권한이 우선
**해결**: 개별 권한 제거 후 그룹 권한만 사용

### 3. "경고" vs "차단" 헷갈림
- **경고**: 수정 가능, 경고 메시지만 뜸
- **차단**: 수정 불가
- 헤더/수식은 **차단**, 일반 데이터는 **경고**가 적절

### 4. 보호 설정이 데이터 입력 차단
**증상**: 에이전트가 신청 입력 못함
**원인**: 너무 광범위하게 보호 설정
**해결**: 입력 가능 범위는 보호 제외
