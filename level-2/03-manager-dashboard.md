## 🛠️ 실행 단계

### Step 1: 대시보드 시트 생성

1. 시트 하단 `+` 클릭 → 새 시트
2. 이름: `매니저대시보드`
3. 탭 색상: 파랑 (식별 쉽게)

---

### Step 2: 상단 헤더 + 날짜

#### A1:H3 헤더 영역

```
A1 셀: =CONCATENATE("📊 Lidia 운영 대시보드 - ", TEXT(TODAY(), "yyyy-mm-dd dddd"))
서식:
  - A1:H1 병합
  - 폰트 크기: 18
  - 굵게
  - 배경: #1A73E8 (파랑)
  - 글자: 흰색
  - 가운데 정렬
```

---

### Step 3: KPI 카드 4개 (한 줄)

```
A5: =COUNTIF(메인트래커!H:H, "대기")          ← 승인 대기 카운트
A6: "⏳ 승인 대기"

C5: =COUNTIFS(메인트래커!H:H, "승인", 메인트래커!M:M, "")  ← 진행 중
C6: "✅ 진행 중"

E5: =COUNTIF(메인트래커!Q:Q, "D-1") + COUNTIF(메인트래커!Q:Q, "D-2") + COUNTIF(메인트래커!Q:Q, "D-3") + COUNTIF(메인트래커!Q:Q, "마감")
E6: "🔴 D-Day 임박"

G5: =COUNTIFS(메인트래커!M:M, "성공", 메인트래커!J:J, ">="&EOMONTH(TODAY(),-1)+1)
G6: "💰 이번 달 성공"
```

#### KPI 카드 서식

각 KPI 카드 영역 (A5:B7, C5:D7, E5:F7, G5:H7):
```
- A5:B6 병합 (숫자)
- 숫자 폰트: 32, 굵게
- 라벨 (A7:B7) 폰트: 12
- 테두리: 외곽 두꺼움
- 배경:
  - 승인 대기: #FFF2CC (노랑)
  - 진행 중: #D4EDDA (초록)
  - D-Day 임박: #F8D7DA (빨강)
  - 이번 달: #D1ECF1 (파랑)
```

### Step 4: D-Day 임박 케이스 리스트

```
A10: "🚨 즉시 조치 필요 (D-Day 임박)"
서식: 폰트 14, 굵게, 배경 #F8D7DA

A11: 다음 QUERY 수식
```

```excel
=QUERY(메인트래커!A2:Z1000,
  "SELECT A, C, D, F, Q
   WHERE Q CONTAINS 'D-1'
      OR Q CONTAINS 'D-2'
      OR Q CONTAINS 'D-3'
      OR Q = '마감'
   ORDER BY Q ASC
   LABEL A 'NO', C 'Agent', D '학부모', F '사유', Q 'D-Day'", 0)
```

수식이 자동으로 표 형태로 펼쳐집니다.

### Step 5: 에이전트별 성과 차트

#### 5-1. 성과 데이터 영역 (A30:C40)

```
A30: "에이전트"
B30: "성공"
C30: "총건수"
D30: "성공률"
```

```excel
A31 (에이전트마스터에서 가져오기):
=QUERY(에이전트마스터!A2:A20, "SELECT A WHERE A IS NOT NULL", 0)

B31 (성공 건수):
=COUNTIFS(메인트래커!C:C, A31, 메인트래커!M:M, "성공",
          메인트래커!J:J, ">="&EOMONTH(TODAY(),-1)+1)

C31 (총 건수):
=COUNTIFS(메인트래커!C:C, A31,
          메인트래커!J:J, ">="&EOMONTH(TODAY(),-1)+1)

D31 (성공률):
=IF(C31=0, 0, B31/C31)
서식: 백분율
```

#### 5-2. 차트 삽입

1. A30:D40 선택
2. **삽입 → 차트**
3. 차트 종류: 가로 막대 그래프
4. 데이터 범위: A31:A40 (이름), D31:D40 (성공률)
5. 위치: 대시보드 시트로 이동

특정 에이전트나 기간으로 동적 필터링:

4. 대시보드에 배치

### 2. 미니 차트 (스파크라인)

각 에이전트 옆에 트렌드 표시:

```excel

```

### 3. 조건부 KPI

목표 달성 여부에 따라 색상 변경:

```excel
A5 (이번 달 성공):
조건부 서식:
  - 30건 이상: 초록 배경
  - 20-29건: 노랑
  - 19건 이하: 빨강
```

### 4. 비교 지표

전주/전월 대비:

```
이번 주 신청: 15건 (▲ 3건)
이번 달 성공률: 65% (▼ 5%p)
```

수식:
```excel
=COUNTIFS(...) & " (" & IF(...>0, "▲ ", "▼ ") & ABS(...) & ")"
```

## ⚠️ 자주 발생하는 실수

### 1. QUERY 컬럼 알파벳 오류
**증상**: 잘못된 컬럼 데이터 표시
**원인**: A=신청번호, B=신청일, ...이 시트마다 다를 수 있음
**해결**: 실제 시트 구조 확인 후 컬럼 알파벳 수정

### 2. COUNTIFS 날짜 비교 오류
**증상**: 이번 달 카운트가 0
**원인**: `">="`와 날짜 사이에 `&` 누락
**해결**:
```
❌ "EOMONTH(TODAY(),-1)+1"
✅ ">="&EOMONTH(TODAY(),-1)+1
```

### 3. 차트가 빈 데이터 표시
**증상**: 차트에 빈 행 포함됨
**해결**: 데이터 범위를 동적으로 (예: `A2:A` 대신 `A2:A100`)

### 4. 대시보드 느려짐
**증상**: 시트 열 때 10초 이상
**원인**: QUERY 수식이 1000+ 행 처리
**해결**: 범위를 필요한 만큼만 (예: `A2:Z1000` → `A2:Z500`)
