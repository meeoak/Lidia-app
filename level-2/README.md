## 🎯 Level 2의 핵심 아이디어

### Before (Level 1)
- 하나의 메인 트래커에 모든 정보
- 필터 뷰로 본인 케이스만 보기
- 여전히 다른 사람 데이터가 보임 (정보 과부하)

### After (Level 2)
- 메인 트래커는 데이터 저장소
- 각 역할마다 **전용 시트** 존재
- 본인 관련 정보만 표시 + 본인이 해야 할 액션 강조

### 작동 원리

```
[메인 트래커]  (마스터 데이터)
       ↓ QUERY/FILTER 수식으로 데이터 가져오기
       ↓
┌──────────────┬──────────────┬──────────────┐
│ 에이전트 시트  │  교사 시트     │ 매니저 대시보드 │
│ (본인 케이스) │ (본인 수업)    │ (전체 요약)    │
└──────────────┴──────────────┴──────────────┘
```

핵심: **데이터는 한 곳에**, **뷰는 여러 개**

## 🛠️ 핵심 기술: QUERY와 FILTER 함수

Level 2에서 가장 많이 사용할 두 함수:

### QUERY 함수
SQL-like 문법으로 복잡한 조건 지원.

```
=QUERY(메인트래커!A2:Z1000,
       "SELECT A, B, C WHERE D = 'GiAR' AND H = '대기'
        ORDER BY B DESC", 0)
```

- `A2:Z1000`: 데이터 범위
- `SELECT A, B, C`: 가져올 컬럼
- `WHERE`: 조건
- `ORDER BY`: 정렬
- `0`: 헤더 없음 (1이면 헤더 포함)

### FILTER 함수
간단한 필터링에 적합.

```
=FILTER(메인트래커!A2:Z1000,
        메인트래커!D2:D1000 = "GiAR",
        메인트래커!H2:H1000 = "대기")
```

- 첫 번째 인자: 가져올 데이터
- 두 번째 이후: 필터 조건

### 언제 무엇을 쓸까?

| 상황 | 추천 |
|---|---|
| 컬럼 일부만 가져오기 | QUERY |
| 정렬 + 집계 | QUERY |
| 단순 필터링 | FILTER |
| 여러 조건 AND/OR | QUERY |
| 실시간 동기화 | 둘 다 가능 |

## ⚠️ Level 2 시작 전 주의사항

### 1. 메인 트래커 데이터 일관성 확인
QUERY/FILTER는 데이터가 일관성 있어야 작동.
- 에이전트 이름 표기 통일 확인
- 빈 행 없는지 확인
- 데이터 타입 통일 (날짜는 날짜, 숫자는 숫자)

### 2. 시트 권한 미리 계획
각 전용 시트의 권한:

```
에이전트 시트:
  - 본인: 편집 가능 (입력 영역만)
  - 다른 에이전트: 접근 불가 (시트 숨김)
  - 매니저: 전체 보기 가능

교사 시트:
  - 본인: 편집 가능 (수업 결과 입력)
  - 다른 교사: 접근 불가
  - 매니저: 전체 보기 가능

매니저 대시보드:
  - 매니저+본부장: 편집 가능
  - 그 외: 보기만
```

### 3. 수식 보호 우선
QUERY/FILTER 수식이 실수로 삭제되면 데이터 안 보임.
→ Level 1의 시트 보호 설정 필수.
