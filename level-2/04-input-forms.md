# Level 2 - Input Forms: 입력 폼 분리

> **목표**: 데이터 입력 안정성 + UX 개선
> **소요 시간**: 2시간
> **선행 작업**: 메인 트래커 구조 확정

---

## 🎯 왜 폼이 필요한가?

### 문제: 메인 트래커 직접 입력
- 에이전트가 빈 행 찾기 어려움
- 실수로 다른 행 수정 가능
- 필수 입력 미체크 가능
- 컬럼 순서 헷갈림

### 해결: Google Forms 사용
- 필수 항목 자동 체크
- 입력 검증 (날짜 형식, 전화번호 등)
- 모바일 최적화 자동
- 메인 트래커에 자동 추가

### Step 3: 응답 시트 연결

1. 폼 상단 **응답** 탭
2. **스프레드시트 아이콘** 클릭
3. 새 스프레드시트 만들기 OR 기존 시트 선택

#### 3-1. 기존 메인 시트에 연결 (권장)

```
"기존 스프레드시트 선택"
→ Lidia 운영시트 선택
→ 새 시트 자동 생성: "폼 응답 1"
```

#### 3-2. 응답 시트 → 메인 트래커 동기화

폼 응답이 자동으로 메인 트래커에 추가되도록 수식 추가.

**메인트래커 시트에 추가**:

```excel
A1001 부터 (또는 마지막 데이터 다음 행):
=QUERY('폼 응답 1'!A2:M1000,
  "SELECT A, F, B, C, D, H, I, ...
   WHERE A IS NOT NULL", 0)
```

**또는 ARRAYFORMULA**:

```excel
메인트래커 시트 새 컬럼 (예: AA2):
=ARRAYFORMULA(IF(LEN('폼 응답 1'!A2:A)>0,
  '폼 응답 1'!A2:A,  ← 타임스탬프
  ""))
```

#### 3-3. 더 간단한 방법: Apps Script (Level 3에서)

폼 제출 시 자동으로 메인 트래커에 행 추가:

```javascript
function onFormSubmit(e) {
  const responses = e.values;
  const tracker = SpreadsheetApp.openById("...").getSheetByName("메인트래커");
  tracker.appendRow([
    "",  // NO (자동 증가)
    responses[6],  // 첫 만남 일자
    responses[1],  // 에이전트
    responses[2],  // 학부모
    // ...
  ]);
}
```

### Step 3: 폼 사전 채우기 URL

교사 시트에서 폼 링크 클릭 시 본인 이름 자동 입력:

```
폼 URL 기본:
https://docs.google.com/forms/d/{FORM_ID}/viewform

사전 채우기 URL:
https://docs.google.com/forms/d/{FORM_ID}/viewform?usp=pp_url&entry.{ENTRY_ID}=Bu+Rina

교사 시트 A71 수식:
=HYPERLINK(
  "https://docs.google.com/forms/d/{FORM_ID}/viewform?usp=pp_url&entry.123456=" & A1,
  "📝 수업 결과 입력"
)
```

#### Entry ID 찾는 법

1. 폼 → 미리보기
2. F12 (개발자 도구) → Console
3. 다음 스크립트 입력:

```javascript
document.querySelectorAll('[name^="entry"]').forEach(e => {
  console.log(e.name + ' = ' + e.closest('[role="listitem"]').querySelector('[role="heading"]').textContent);
});
```

각 항목별 entry ID 출력됨.

## 📱 폼 UX 최적화

### 1. 폼 디자인

```
설정 → 폼 설정 → 디자인:
- 머리글 이미지: Lidia 로고
- 색상 테마: 브랜드 컬러
- 폰트: 한글/영문 모두 지원
```

### 2. 응답 확인 메시지

```
설정 → 프레젠테이션:
- 응답 확인 메시지:
  "감사합니다! 매니저 검토 후 알려드릴게요.
   ⏰ 평균 검토 시간: 2시간"
- 다른 응답 제출 링크: 표시
- 응답 편집 가능: 가능 (24시간 내)
```

### 3. 모바일 최적화

Google Forms는 자동 모바일 최적화. 단:
- 한 페이지에 너무 많은 항목 X
- 섹션 분리 (3-5개 항목씩)
- 진행 표시줄 활성화

```
설정 → 프레젠테이션 → 진행률 표시 ✅
```

### 4. 빠른 입력 단축키

자주 입력하는 정보는 자동 채우기:

```
폼 URL에 파라미터 추가:
?usp=pp_url
&entry.111111=GiAR        ← 에이전트
&entry.222222=Jakarta+Pusat ← 자주 가는 지역

이 URL을 즐겨찾기 → 1초 입력 시작.
```

## ⚠️ 자주 발생하는 실수

### 1. 응답 시트 컬럼 순서
**증상**: QUERY 결과가 이상한 컬럼
**원인**: 폼 항목 순서 변경 시 응답 시트 컬럼 순서 변경됨
**해결**: 폼 완성 후 항목 순서 변경 자제. 변경 시 모든 수식 점검.

### 2. 필수 항목 미체크
**증상**: 빈 값으로 응답 추가됨
**해결**: 모든 중요 항목에 "필수" 체크 ✅

### 3. 응답 시트 직접 수정
**위험**: 폼 응답 시트를 직접 수정하면 향후 응답이 잘못 추가됨
**해결**: 폼 응답 시트는 보호 설정 → 매니저만 수정 가능

### 4. 폼 응답 한도
**한도**: Google Forms - 응답 최대 5,000,000개 (실용상 무제한)
**시트 한도**: 1,000만 셀
**대응**: 응답 수가 많으면 월별로 시트 분리

### 5. 파일 업로드 권한
**문제**: 외부 사용자가 파일 업로드 못함
**해결**: 설정 → 응답 → "Google 계정 로그인 필요" 비활성화
